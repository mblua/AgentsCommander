Prototype: agent order controls (issue #2311, epic #2306)

Static visual prototype. No application code, no persistence — the save step is mocked.

  • Up/down buttons swap rows immediately.
  • Press "Select" on any card, then reorder: the same agent stays selected. Selection is shown by a "Selected" chip as well as colour, and is exposed as aria-current.
  • First row's Up and last row's Down are disabled.
  • While the filter is active, reordering is disabled and the reason is shown.
  • Toggle the mocked save failure below to see the error state.
  • Resize to a narrow viewport (≤420px) to see the stacked layout.
