# AgentsCommander

You opened AgentsCommander. Start here when you want to turn a project, a set of agent roles, and one or more tasks into coordinated rooms.

Use the Agent Commander / Root Agent when work spans more than one team or room instance. It gives you one place to talk to room orchestrators, ask different teams to take on tasks, and keep initiatives aligned across parallel rooms.

## Start fast

1. Open or create an AgentsCommander project.
   Use an existing repo or create a new project folder. AgentsCommander stores the Project AC Root, agents, teams, and message files inside that project.
2. Create the agents you need.
   Give each agent one clear role, such as orchestrator, backend developer, reviewer, tester, or technical writer. Clear roles make delegation easier to review.
3. Create teams or rooms.
   Pick one orchestrator per team and add the worker agents that should handle the task. Orchestrators plan and delegate; workers focus on their assigned parts.
4. Launch the orchestrator.
   Open the orchestrator session from the sidebar and choose the coding-agent runtime when prompted.
5. Send the first task.
   Tell the orchestrator the outcome you want, the constraints that matter, and the files or docs it should inspect first.
6. Review each agent's output.
   Read the orchestrator summary, inspect worker replies, verify changed files, and decide what should continue, stop, or ship.
