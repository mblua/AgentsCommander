# Agents Commander v0.40.0

### Added

- **Coding agents have tips and a Best Practices window.** Each agent card in Settings > Coding agents has a Tips button that shows that agent's tips, and a new **Best Practices** button shows the general tips, with a params placeholder and a docs link per agent. The tips ship with AC and can be refreshed from the project's published file at startup, at most once every 24 hours; a local `agent-help.local.json` can add to them, and if it is invalid both windows say why it was ignored. ([#2136](https://github.com/mblua/AgentsCommander/issues/2136), [#2137](https://github.com/mblua/AgentsCommander/issues/2137), [#2138](https://github.com/mblua/AgentsCommander/issues/2138), [#2139](https://github.com/mblua/AgentsCommander/issues/2139), [#2143](https://github.com/mblua/AgentsCommander/issues/2143), [#2144](https://github.com/mblua/AgentsCommander/issues/2144), [#2145](https://github.com/mblua/AgentsCommander/issues/2145))
- **Agent chips show the weekly (7-day) quota as a fill.** The agent chip on origin sessions and on room replicas is filled red for the used share and green for the rest, read from the coding agent's statusline; Claude Code is supported first. Each coding agent has a new weekly quota pattern field in Settings with a suggested pattern, and the reading is shared per agent, so a replica with no session shows its configured agent's value. ([#2494](https://github.com/mblua/AgentsCommander/issues/2494), [#2495](https://github.com/mblua/AgentsCommander/issues/2495), [#2496](https://github.com/mblua/AgentsCommander/issues/2496), [#2497](https://github.com/mblua/AgentsCommander/issues/2497), [#2498](https://github.com/mblua/AgentsCommander/issues/2498), [#2499](https://github.com/mblua/AgentsCommander/issues/2499), [#2500](https://github.com/mblua/AgentsCommander/issues/2500), [#2501](https://github.com/mblua/AgentsCommander/issues/2501), [#2591](https://github.com/mblua/AgentsCommander/issues/2591), [#2592](https://github.com/mblua/AgentsCommander/issues/2592))
- **Room numbers can be zero-padded with a mask.** The new `roomNumberMask` setting (default `#`, 1 to 9 `#` characters) sets the minimum width of new room numbers; Settings shows a live example and rejects an invalid mask on save. Wider numbers are never cut, existing rooms are not renamed, and with the default the names are the same as before. ([#2509](https://github.com/mblua/AgentsCommander/issues/2509), [#2510](https://github.com/mblua/AgentsCommander/issues/2510), [#2511](https://github.com/mblua/AgentsCommander/issues/2511))
- **`room activity` gained filters and CI details.** New flags `--rooms`, `--team`, `--working true|false`, `--ci-state running|idle|unknown`, `--title-regex` and `--hide-clean` combine with AND; an invalid value or regex exits 1 with a clear error. The JSON output adds `ciRunIds`, `ciPullRequests` and `ciUnknownReason`, and existing fields are unchanged. ([#2473](https://github.com/mblua/AgentsCommander/issues/2473))
- **The Resource Monitor has a column header strip.** Agent, State, Procs, Private, Working set and CPU captions sit above the agent rows and stay visible while scrolling when the pane is at least 860px wide; narrower panes show tooltips on the cells instead. ([#2582](https://github.com/mblua/AgentsCommander/issues/2582))
- **The selection-lock panel explains its counts.** The agent picker names each replica that the protection count skipped and why, and the counter says `counting…`, `not counted yet` or `count failed` instead of bare symbols. ([#2557](https://github.com/mblua/AgentsCommander/issues/2557), [#2556](https://github.com/mblua/AgentsCommander/issues/2556), [#2572](https://github.com/mblua/AgentsCommander/issues/2572))

### Changed

- **Co-managed is now off for the whole app by default, because the feature is in development.** A new global switch, `coManagedEnabled` in `settings.json`, defaults to `false`. While it is off, no room is co-managed, the **Co-managed** checkbox is not drawn and AC makes no Jev calls. Rooms you already enabled become inert when you update; their `.co-managed/config.json` is left untouched, so they come back as they were once you turn the switch on. To turn it on, add `"coManagedEnabled": true` to `settings.json` and restart AC; there is no UI control. ([#2491](https://github.com/mblua/AgentsCommander/issues/2491))
- **Releases are published to the npm `next` dist-tag first.** Every release now goes to `@mblua/agentscommander@next`, and `latest` only moves when a maintainer promotes the tested version by hand. The GitHub Release is not marked latest when published, and the in-app update notice appears only after promotion. The npm README tells testers how to install `@next` and links the `#testers` Discord channel. ([#2029](https://github.com/mblua/AgentsCommander/issues/2029))
- **Coding agents are reordered by drag and drop.** Settings > Coding Agents and the Assign profile agent picker replace the up/down arrows with a grip you drag, plus keyboard pick-up (Space, arrows, Escape; Alt+Up/Down in the picker). Expanding the Coding Agents card with its chevron now also selects the agent rail. ([#2542](https://github.com/mblua/AgentsCommander/issues/2542), [#2543](https://github.com/mblua/AgentsCommander/issues/2543), [#2544](https://github.com/mblua/AgentsCommander/issues/2544), [#2545](https://github.com/mblua/AgentsCommander/issues/2545), [#2577](https://github.com/mblua/AgentsCommander/issues/2577), [#2594](https://github.com/mblua/AgentsCommander/issues/2594))
- **Coding-agent profiles are matched by a portable identity.** The profile hash is now the same for the same configuration on every OS, so after updating, existing sessions show as outdated until relaunched. A session's coding agent is resolved by hash, then label, then command, and a restart whose agent can no longer be resolved fails with `unresolved_coding_agent_reference` and keeps the old session instead of guessing. Session and replica rows show a badge (`B·nombre` or `B·cmd`) when the profile was matched by agent name or by command. ([#2430](https://github.com/mblua/AgentsCommander/issues/2430), [#2431](https://github.com/mblua/AgentsCommander/issues/2431), [#2433](https://github.com/mblua/AgentsCommander/issues/2433), [#2434](https://github.com/mblua/AgentsCommander/issues/2434), [#2450](https://github.com/mblua/AgentsCommander/issues/2450), [#2451](https://github.com/mblua/AgentsCommander/issues/2451), [#2435](https://github.com/mblua/AgentsCommander/issues/2435))
- **The profile params field wraps and grows while you edit it.** It no longer scrolls sideways; it expands to show the full text on focus and collapses on blur. Params stay on one line: Enter is ignored and pasted newlines become spaces. ([#2597](https://github.com/mblua/AgentsCommander/issues/2597))
- **The delivered Loop toast says more.** It reads `Loop "<name>" delivered to room N · next <local time>`, leaving out the room or the next time when it is unknown. ([#2538](https://github.com/mblua/AgentsCommander/issues/2538))
- **Resource Monitor warnings sit above the agent rows and name the agent.** Each warning names the agent, room, CLI, size and limit and links to its row; the warnings no longer paint over the rows. ([#2581](https://github.com/mblua/AgentsCommander/issues/2581))

### Removed

- **The Resource Monitor's network placeholder is gone.** Per-agent socket attribution was never implemented, so the row network pill and the header Network tile are removed, and a healthy snapshot now reports `OK` instead of Unknown in the header and the sidebar badge. ([#2583](https://github.com/mblua/AgentsCommander/issues/2583))

### Fixed

- **Restart errors are in plain words and no longer silent.** When a session's coding agent is no longer in Settings, the restart says so and tells you how to pick another one, instead of showing `unresolved_coding_agent_reference`. Waking a stopped replica and right-click > Restart now show a toast when they fail. ([#2573](https://github.com/mblua/AgentsCommander/issues/2573))
- **Coding agents are found when AC is launched from the desktop on Linux and macOS.** AC now adds the usual user folders and the login shell's PATH when looking up an agent CLI, so updates no longer fail with `exit code 127` and installed CLIs no longer show as "not installed". Windows is unchanged. ([#2589](https://github.com/mblua/AgentsCommander/issues/2589))
- **Detached terminal windows close when the app closes.** They are still restored on restart. ([#2563](https://github.com/mblua/AgentsCommander/issues/2563))
- **Co-managed rooms behave correctly when enabled.** The replica row shows the Co-managed message, the row no longer stays busy after the idle edge, the Claude reader attaches to the new session's own transcript, Room reader demand is re-raised when readiness changes and released when co-managed is globally off, a raise racing a disable no longer leaves a demand behind, and the flow is logged for diagnosis. ([#2452](https://github.com/mblua/AgentsCommander/issues/2452), [#2453](https://github.com/mblua/AgentsCommander/issues/2453), [#2454](https://github.com/mblua/AgentsCommander/issues/2454), [#2455](https://github.com/mblua/AgentsCommander/issues/2455), [#2456](https://github.com/mblua/AgentsCommander/issues/2456), [#2516](https://github.com/mblua/AgentsCommander/issues/2516), [#2525](https://github.com/mblua/AgentsCommander/issues/2525))
- **Agent picker previews no longer wait on each other.** The three selection previews share a read turn instead of queueing one at a time. ([#2485](https://github.com/mblua/AgentsCommander/issues/2485))
- **Sidebar readability fixes.** Rail section headers are brighter and bold, the rail Favorites header is no longer clipped, both rail scrollbars line up and use a thin style, the agent chip is readable in the light theme with a stronger dark palette and a redder quota-used tint, and the root banner `>>` toggle is white in the dark theme while the compact row keeps its height. ([#2467](https://github.com/mblua/AgentsCommander/issues/2467), [#2584](https://github.com/mblua/AgentsCommander/issues/2584), [#2578](https://github.com/mblua/AgentsCommander/issues/2578), [#2512](https://github.com/mblua/AgentsCommander/issues/2512), [#2565](https://github.com/mblua/AgentsCommander/issues/2565), [#2519](https://github.com/mblua/AgentsCommander/issues/2519))
- **Escape closes the restart prompt and the context-files panel**, the same as clicking the backdrop. ([#2660](https://github.com/mblua/AgentsCommander/issues/2660))

### Security

- **Hardening from a SonarCloud security pass.** The remote access token and window type read from the URL are validated, reconnect jitter uses a cryptographic random source, the session-bridge Docker image runs as `nobody`, npm installs in CI and Docker skip install scripts, and workflow permissions are set per job. Valid input behaves as before. ([#2645](https://github.com/mblua/AgentsCommander/issues/2645), [#2646](https://github.com/mblua/AgentsCommander/issues/2646), [#2649](https://github.com/mblua/AgentsCommander/issues/2649), [#2651](https://github.com/mblua/AgentsCommander/issues/2651), [#2653](https://github.com/mblua/AgentsCommander/issues/2653))
